# CLAUDE.md

**Current version: 2.07.00.** With every deployed change, bump `version:` in `content/site.md` and update this line in each `.md` file at the top of the project (AGENTS.md, CLAUDE.md, README.md, future.md, completed.md) to match; the build fails if they disagree.

When writing anything for this site (content, the blog, commit messages, these docs):
write like a person, plainly and specifically, and never use em dashes (the long dash,
U+2014). Use a comma, a colon or two sentences instead. The build fails on an em dash in
`content/`. Full rules are under "Writing" in AGENTS.md.
