# Future changes

**Current version: 2.07.02.** With every deployed change, bump `version:` in `content/site.md` and update this line in each `.md` file at the top of the project (AGENTS.md, CLAUDE.md, README.md, future.md, completed.md) to match; the build fails if they disagree.

Changes to make to the site. Write each one as a bullet under **To do**, in plain words,
with whatever details help (links, dates, text to use, where a picture is). Agents read
this at the start of a session, ask before doing anything, test the change locally, and
then move it to [`completed.md`](completed.md). See [`AGENTS.md`](AGENTS.md).

For example:

> - I made another project called "x". The details are at https://x.com; it's about …
>   Use the logo in ~/Downloads/x-logo.png.
> - Update my resume with the PDF in ~/Downloads, and add a "Machine Learning" resume.
> - Change the Summary tile's text to "About me".
